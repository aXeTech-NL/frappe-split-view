# Security policy

## Supported versions

This repository is pre-release and experimental. No version is currently supported for production
security updates. This policy will be revised before a public release.

## Reporting a vulnerability

Please do **not** disclose suspected vulnerabilities in a public issue. Use GitHub's private
vulnerability reporting feature for this repository when it is enabled.

If private vulnerability reporting is unavailable, contact the repository maintainer privately
through a channel the maintainer publishes before public launch. No security email is listed because
no project-controlled address has been established; maintainers must configure a private channel
before public launch.

Include affected versions, reproduction steps, impact, and any suggested mitigation. Maintainers
should acknowledge a report privately, coordinate remediation and disclosure, and avoid exposing
reporter details without consent.
